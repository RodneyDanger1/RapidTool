## 1. Root cause (verified live, pre-fix)

- `scaffold.ts:642` emitted `src/api/routes.ts` with
  `throw new Error(\`TODO(E-15 stub): implement ${method} ${path}\`)` — the paren
  closes after **stub**: `TODO(E-15 stub)`.
- `scaffold.ts:1102` emitted `tests/oracle.spec.ts` with the reject assertion
  `/TODO\(E-15\) stub/` — the canonical register form, paren closes after **15**:
  `TODO(E-15) stub` (same canonical form already used in the spec's own comments,
  `scaffold.ts:1096`, and internal comments :732/:872/:913).
- Runtime error: `Error: TODO(E-15 stub): implement POST /v1/dispatch` → the
  regex `/TODO\(E-15\) stub/` does NOT match → every oracle stub-rejection row
  (`orc-*`-style endpoint rows) failed → M2 = 0 on every webapp emit with A6
  endpoints. 11 emitted-marker sites in `scaffold.ts` carried the wrong paren
  form; all canonicalized.
