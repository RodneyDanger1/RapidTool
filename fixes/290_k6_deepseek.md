## Docs captured (api-docs.deepseek.com, 2026-09-27, K6 reads via curl+HTML extract)

Fetched: `/guides/kv_cache`, `/api/create-chat-completion`, `/quick_start/error_codes`, `/guides/thinking_mode`, `/guides/json_mode`, `/quick_start/pricing`, `/quick_start/rate_limit`.

- **Context Caching** (`/guides/kv_cache`): automatic prefix caching, on by default, no config. The hard disk cache **only matches the prefix** of the input. A request hits only if it **fully matches a persisted "cache prefix unit"**. Units are persisted at: (a) request boundaries — end of user input / end of model output; (b) **common-prefix detection across requests** (the shared prefix is persisted as an independent unit — this is what multi-chunk synthesis can exploit); (c) fixed token intervals for long inputs. Best-effort, no guarantee; construction takes seconds; cleared when unused, usually hours→days. Hit status: `usage.prompt_cache_hit_tokens` / `usage.prompt_cache_miss_tokens` ("Checking Cache Hit Status"). Output is still computed (temperature adds randomness — cache ≠ deterministic output).
- **Chat Completions API** (`/api/create-chat-completion`): `thinking` = `{type: enabled|disabled}`, **default enabled**; `reasoning_effort` = `[none, low, high, max]`, default `high` (`none` disables thinking; `minimal`→low, `medium`/`xhigh`→high for compat). `max_tokens`: 1..384K (393216); **default 8K non-thinking, 64K thinking** (128K at `reasoning_effort:max`). `temperature`: default 1, range 0..2, **"Has no effect in thinking mode"**. `response_format {type:"json_object"}` requires an explicit JSON instruction in system/user (module adds one). `stream` = SSE; `stream_options.include_usage` (usage on the last chunk only). Usage shape: `prompt_tokens = prompt_cache_hit_tokens + prompt_cache_miss_tokens`; `prompt_tokens_details.cached_tokens` = same as hit; `completion_tokens_details.reasoning_tokens`.
- **Error codes** (`/quick_start/error_codes`): 400 Invalid Format · 401 Authentication Fails · **402 Insufficient Balance** (→ top up) · 422 Invalid Parameters · 429 Rate Limit Reached (pace requests) · 500 Server Error (retry after brief wait) · 503 Server Overloaded (retry after brief wait).
- **Pricing** (`/quick_start/pricing`): per 1M input — flash (off-peak) **cache hit $0.003 vs miss $0.15 → 50×**; peak hit $0.006 / miss $0.3. Pro off-peak hit $0.022 / miss $0.66; peak $0.044 / $1.32. Context 1M, max output 384K. Concurrency flash 2500 / pro 500. **Canonical request id is now `deepseek-flash`**; legacy `deepseek-v4-flash` "still accepted", served by DeepSeek-V4.1-Flash, billed at flash price.
- **Rate limit & isolation** (`/quick_start/rate_limit`): after send, the HTTP connection stays open — non-streaming responses may stream **empty lines** as keep-alive (JSON.parse tolerates them; the module's text→JSON.parse path is safe), streaming uses `: keep-alive` comments. **Server closes the connection if inference has not started after 10 minutes** — the module's client timeouts (20s/60s/90s, injectable) always fire first → honest `RT_E_LLM_TIMEOUT`, never the vendor cutoff. Concurrency overflow ⇒ 429. `user_id` enables per-user KV-cache isolation (RapidTool does not send it — no-op note).
- **JSON Output** (`/guides/json_mode`): set `response_format`, include the word "json" + an example, set `max_tokens` reasonably; the vendor itself acknowledges occasional **empty content** (the module's empty-content diagnostics + fixes/156 E1 `thinking:false` are the mitigations).
