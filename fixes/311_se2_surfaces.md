## 2 · Unattended / scheduler path

So a fresh brief **parks at P4 with exit 2** (honest, never a fake completion). `RT_E_UNATTENDED_UNSUPPORTED` (`errors.ts:533-538`) is registered-but-unthrown on the landed verb path.
**Human touchpoints left (fresh brief → built app):** ① P4 · ② P5 · ③ P8 · ④ P9 approvals (×4 per clean run; more after reject/repair); ⑤ `blocked` → retry is human (`RT_E_PHASE_ILLEGAL…unlock:human-retry`, `engine.ts:4310-4325`); ⑥ hard-DoD park → repair/re-run; ⑦ wild start/pause/resume are explicit verbs; ⑧ arming the cron/Task-Scheduler hook (no scheduler file in-repo — `grep -rn cron` = comments/docs only); ⑨ host key provisioning; ⑩ emitted-tree deploy handoff.
