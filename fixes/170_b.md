### 18.7 The 5 most likely ways an agent BREAKS this codebase — and how to avoid each

1. **Byte-parity violation.** Editing a pinned string/shape (`prompt-engine` strings, keyless/no-fixture emissions, the deepseek ok-return, PKG_SCRIPTS) breaks ~1447 frozen-baseline tests at once; adding a field defaulted to `[]`/`false`/`""` instead of ABSENCE changes serialization. **Avoid:** additive-absence-only fields; run the frozen-baseline tests after EVERY edit; on failure, revert the pinned-string edit — do not "fix" the test.
2. **Client-bundle build break.** A static OR dynamic import of `node:fs` or a `*.server.ts` module (or a `.tsx` entry import) reaching the console path fails `npm run build`. **Avoid:** concatenated-spec lazy import + `typeof window` guard, `import type` for server types, and run `npm run build` after every single item — it is the guard, not a chore.
3. **Env-key leak flips the suite red (or worse).** Sourcing `.env` in the gate shell makes keyless store tests hit the P6 hard-DoD block; an agent then "fixes" green code chasing a ghost — or accidentally runs keyed and records non-reproducible results. **Avoid:** keyed runs only in child subshells; `unset DEEPSEEK_API_KEY` after probes; never `. .env` in the foreground gate shell.
4. **Recording success past a red/hard gate** — the F2/F3/9.6/165-C-1 cluster: `executeAsync` returns `ok:true` on `dodBlocked`; headless `advanceOnce` bypasses enforceDod (CLI/eval drain past P10); `driveP6Journey`/`repairTreeDir` mint `tested` before reading `gate.passed`. **Avoid:** gate-first ordering everywhere; ONE leave-gate predicate mirrored at every site; T0.3/T0.4/T0.6 first, before any Phase-A feature work.
5. **Ledger/disk divergence + fabricated evidence + auto-approval.** M1/M3/M4 read the in-memory ledger while M2/M6 read disk and nothing binds them; tree files are declared that don't exist on disk; a model-written log could masquerade as behavioral evidence; a machine approval can read as human. **Avoid:** the A7 canonical-score gate (re-import the emitted dir hash-checked, score the bound artifact only), behavioral = runner TAP only, real-actor stamps, and R4's no-auto-approve rule — these are the honesty contract, not process suggestions.
