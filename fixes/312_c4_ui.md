### The two a11y extras (C4's flags)
- **Stale rail-section label.** `pipeline-rail.tsx:443`: `aria-label="Pipeline telemetry"` →
  **`"Pipeline telemetry and phase detail"`**. Why: after the strip merge the section contains
  exactly the telemetry rows + the interactive `PhaseRecordDetail` the merged strip opens; the
  interim label named only half of what a screen-reader user finds inside.
- **now-line `aria-atomic` — DECISION: keep `"true"`, documented in-code.**
  Why (full text in the code comment): the region holds exactly one keyed row; the key changes
  only when a new event's `ts` lands, so "whole region" == "the one new event" — announcements
  stay incremental (one landing → one announcement; the 2s poll's no-op re-renders emit no DOM
  mutation, so no spurious re-reads). Atomicity keeps the row one coherent sentence instead of
  AT-diffed fragments; either setting is announcement-equivalent for a single-row region, so
  `"true"` was kept for cross-AT determinism.
