## Bottom line

Every artifact record emitted by `src/lib/codegen.server.ts` now carries an additive, optional
`provenance` block — `artifact.provenance = { producer, model?, timestamp, inputHash }` — populated
from real emit data (served model id from the `LlmResult` actually returned, epoch-ms emit time, and
the FNV-1a of the derivation input). `src/lib/io.ts` validates + preserves that block through
`exportProjectJson` → `importProject` (serializer round-trip pinned by a test), NEVER fabricates it for
legacy rows (types.ts:187 law), and fails closed (drops the whole stamp, loudly) on any contradiction —
a `producer: "deterministic"` stamp can never ride with a model id.

### Exact field names for T5.7 (cite these verbatim)

`artifact.provenance` is an optional object on every artifact record:

| field | type | rule |
|---|---|---|
| `provenance.producer` | `"deterministic" \| "model" \| "replay"` | closed vocabulary (exported as `ARTIFACT_PRODUCERS` from `src/lib/io.ts`). `"deterministic"` = the record's content is machine-derived — never model-stamped. `"model"` = an LLM call produced the record. `"replay"` = a recorded envelope served from a tape (reserved for T5.7 — no writer mints it today; the io validator/round-trip already accept it). |
| `provenance.model` | `string` (optional) | the model id actually served (never the requested id). Present iff `producer !== "deterministic"`. |
| `provenance.timestamp` | `number` | epoch ms (`Date.now()`) at record emission. |
| `provenance.inputHash` | `string` | FNV-1a (32-bit, stringified) of the input the record was derived from — per emit site (below). |

Per-emit-site `inputHash` rule (real data, no invention):

- `codeArtifact` from `upgraded()` (single-module LLM path) and from `treeUpgraded()` (chunked tree path):
  `inputHash = specRecord.briefHash` (the synthesis input — the brief hash the pipeline already persists).
- `verifyOutcomeArtifact()` (machine verify record): `inputHash = String(fnv1a(finalModule + outcome.evidence))`
  — the same evidence hash the artifact id already derives from. `producer: "deterministic"` (the runner's
  evidence text is machine-derived), never carries `model`.

Type location: exported from `src/lib/io.ts` as `ArtifactProvenance` (+ `ARTIFACT_PRODUCERS`). It is NOT yet
folded onto `Artifact` in `src/lib/types.ts` (out of this lane's file box) — the codegen emit sites type
their records as `Artifact & { provenance: ArtifactProvenance }`; a later lane owning `types.ts` can add the
optional field verbatim.
