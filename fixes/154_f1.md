2. **`run-eval.mjs` — wiring.** `evaluateEntry` computes `synthesisSucceeded` for keyed
   runs: `true` iff the final project's logs contain ≥1 `p6.synthesis.attempt` whose
   detail parses to an `ok` outcome (P1's journal format `chunk N/M · attempt N ·
   <ms>ms · ok|refused|timeout`; outcome = the token after the `<ms>ms` budget token, so a
   `· refusal: …` tail can never fake an ok — helper `attemptLogOutcomeIsOk`). Keyless
   runs leave it `undefined` (keyless makes no model calls; an unguarded false would
   vacuous-floor the honest keyless cards). It is passed into `scoreMaker` and persisted

   keyless results.json rows keep their exact legacy shape).
3. **`run-eval.mjs` — loudM1Zero guard.** The "M1=0 ON A CONVERGED KEYED JOURNEY

  mission pins M5-M9 unchanged and the 5/9 headline, which requires M7 intact. Hence
  criteria keep their probe semantics; `scoreMaker` owns the vacuity override.

  never makes a synthesis call → `synthesisSucceeded:false` → floor gate fires with
  evidence reading "all synthesis calls refused". Strictly it is "never attempted", but
  the operative claim — tree/run/mint evidence is the deterministic floor, no
  LLM-produced software exists — is accurate, and the card is already honest-low (M9=0 on
  the stall). A tri-state (attempted-but-refused vs never-attempted) can ride a later
  wave if T wants the wording exact in that corner.
