## Design (v1, in-process only — playbook T5.5 block, 230 lines 1082–1103)

- **Shape:** `PluginHook = { id, apiVersion, kind, writesState?, policy?, run }`; `HookContext =
  { hookId, kind, registryVersion, policy? }`; results are `DispatchReport { ok, kind, outcomes[], code?,
  error? }`; registration returns `{ ok: true, hookId, kind } | CodedFailure`. Refusals reuse
  `codeError`/`CodedFailure` from `errors.ts`; thrown errors reuse `classifyError`.
- **Order contract:** dispatch visits hooks in registration order (successful `register` calls), stated in
  the module header and pinned with reverse-alphabetical ids (`zeta, alpha, mike`) so a key-order accident
  reds the suite; repeat dispatch is stable; late registration appends.
- **Containment contract:** `try/catch` around `hook.run` produces the coded `failed` outcome — never a
  silent catch (the failure is IN the report and in `report.error`), never a host-loop crash (dispatch is
  total; unknown kind is a coded refusal with zero outcomes; malformed registrations never throw).
- **Thenable refusal:** v1 dispatch is synchronous; a thenable return is `RT_E_VALIDATION` ("returned a
  thenable") and `Promise.resolve(result).catch(() => undefined)` neutralizes the settlement — closed as a
  crash class rather than documented away.
- **Policy seam:** registration refuses `writesState: true` without a routable claim
  (`unroutable-policy-claim`: unknown action / empty resource / missing claim), and refuses an inert claim
  without `writesState`. Dispatch calls the REAL `evaluatePolicy` (no injected fake, no mock) with the
  caller's `PolicyCtx`; deny ⇒ `refused` outcome (`RT_E_PERMISSION_DENIED` + policy reason + fallback),
  writer never runs; allow ⇒ verdict handed to the hook in `ctx.policy`.
- **Scope pins:** test-level source scan of `plugin.ts` for dynamic-load / string-eval / Function-ctor /
  network / require / fs-floor / clock / randomness / env tokens (raw source, comments included; scanner
  self-tested against planted violations) + the I4 word absent.
