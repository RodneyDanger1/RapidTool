## 2. The ignore

**Added: `"testruns/**"` to the `ignores` array of `eslint.config.mjs` (one entry, 6 lines with comment).**

Justification, each clause evidenced:

- **It is generated output, not source.** `testruns/**` holds the factory's own **emitted app trees** —
  14 `emitted*` directories (`testruns/<slug>/emitted{,.v2}/src/jobs|generated/*.ts`) plus their run logs.
  The errors are exactly what emitted third-party-shaped app code looks like: 45 `no-var` from the
  scaffold style, and emitted `.tsx`/namespace output.
- **It is untracked.** `git ls-files testruns | wc` → **0**; `git status --porcelain -- testruns` → `?? testruns/`.
  325 files per the W356 log / 1,078 files on disk today — the corpus is regenerated by every factory run.
- **The repo already made this exact call for the same class.** `research/eval-out/**` is ignored in the
  same config with the comment "emitted eval trees carry intentional scaffold `var` style" — the same
  `no-var` class this ignore removes. `testruns/**` is that same artifact class, one directory over.
- **Linting it is not a quality signal about this repo.** A `var` in an emitted app's `src/jobs/*.ts` is a
  signal about the emitter's output style, not about RapidTool's source. Grading the repo on it measures
  the wrong subject — and it would put a green/red gate on a directory that is not even committed.
